P.01

SoccerTwos: Trained RL Agents

Unity ML-AgentsReinforcement LearningPPOSimulation
Description
I built a 2v2 soccer match where every player is an AI agent, trained with reinforcement learning inside Unity's ML-Agents SoccerTwos environment — no scripted behavior, no pathfinding shortcuts. I trained it locally using the standard Unity ML-Agents PPO workflow (mlagents-learn) for 1,000,000 steps on an RTX 3070 Ti. The agents started out moving randomly, and by the end of the run they were regularly intercepting the ball and defending their own goal. This build is inference only, so you're watching the trained policy play, not training live.

P.02

Chroma Blast

Unity 6XR Interaction ToolkitMeta Quest 2/3Photon PUN2/FusionAI Navigation
Description
I built a multi-user, physics-based VR paintball simulator for Meta Quest 2 and 3 with two teammates as our Final Year Project. Projectiles follow real trajectory physics based on velocity and impact instead of instant-hit shooting, so aiming and cover actually matter, and real-time multiplayer runs on Photon. I worked on the physics-based projectile system, the Player vs AI mode, and the spatial UI. The projectile system uses real velocity and impact physics so shots behave like actual paintballs, the AI opponent runs on a navigation mesh with its own decision logic so solo players have something to genuinely train against, and I built the spatial UI to stay readable without getting in the way during fast VR combat.

P.03

Multiverse Odyssey

Unity 6C#Meta Quest 2/3VR InteractionEnvironmental Simulation
Description
I built a VR game set in a realistic Islamabad-inspired city where a sudden flood from Rawal Lake triggers a citywide disaster. Infected creatures emerge from the floodwater, and the player has to solve puzzles, unlock portals, and travel across alternate worlds collecting artifact stones to restore balance. I built the core gameplay mechanics from the ground up in Unity 6 for Meta Quest 2/3: the portal system for traveling between worlds, the puzzle system gating each portal, the artifact/stone collection system, an infection system that spreads through NPCs and pressures the player, and a dynamic water simulation that floods the environment in real time. I mapped VR interaction — movement, grab, and portal activation — to Quest joystick, grip, and trigger input.
